## SEO (82/100) — главная зона для правок

Два проваленных пункта, каждый с весом в оценке:

1. **Нет `meta description`** — в `<head>` отсутствует мета-описание страницы. Нужно добавить осмысленное описание (например: «Онлайн-бронирование…») в `web/index.html`.

2. **`robots.txt` невалидный (13 ошибок)** — эндпоинт `/robots.txt` возвращает HTML-разметку SPA (`index.html`) вместо файла `robots.txt`. Подтверждено напрямую: `https://web-production-e3ae22.up.railway.app/robots.txt` отдаёт `200` с `<html>` внутри. Поисковые роботы не смогут корректно обработать файл. Дополнительно `sitemap.xml` тоже отдаёт HTML — стоит проверить и его.
   - **Причина:** статический хостинг (Railway + SPA Fallback) отдаёт `index.html` для неизвестных путей. Нужен реальный файл `robots.txt` в корне публичной директории.

## Agentic Browsing (67/100) — экспериментальная категория

Новая категория в Lighthouse 13 (проверка пригодности страницы для ИИ-агентов):

- **`/llms.txt` не соответствует рекомендациям** — файл `llms.txt` (стандарт описания сайта для LLM-агентов) отсутствует или оформлен неверно. Пока категория экспериментальная и на основные проверки не влияет.

## Список правок для проекта

Приоритезированный план работ (`web/`-часть, контракт не затрагивается):

1. **[SEO, починить] добавить файл `robots.txt`** — положить валидный `robots.txt` в корень публичной папки Vite (`web/public/robots.txt`), чтобы хостинг отдавал его вместо SPA fallback. Базовое содержимое: `User-agent: *` + `Allow: /` + `Sitemap: <абс. URL>/sitemap.xml`.
2. **[SEO, починить] добавить `meta description`** в `web/index.html`.
3. **[A11y, починить] обернуть содержимое приложения в `<main>`** — добавить landmark `main` в корневой layout (`web/src/App.tsx` / общий шаблон), чтобы устранить `landmark-one-main`.
4. **[Практика, по желанию] включить source maps в production-сборку** Vite для упрощения отладки (`build.sourcemap`).
5. **[Производительность, по желанию] код-сплиттинг** — разнести один SPA-бандл по маршрутам (React.lazy / route-level chunks), чтобы сократить ~88 КБ неиспользуемого JS на главной.
6. **[Agentic/эксперимент, по желанию] добавить `llms.txt`** в корень проекта для описания сайта ИИ-агентам.
