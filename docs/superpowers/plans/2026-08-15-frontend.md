# Frontend Calendar Booking Service — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Vite + React + TS приложение в `/workspace/web`: флоу гостя (типы событий → свободные слоты → бронирование) и админка (типы событий, предстоящие брони), работающее в dev против Prism-мока на контракте.

**Architecture:** Один SPA. Типы генерируются из `dist/openapi.yaml` через `openapi-typescript`; запросы — типобезопасный `openapi-fetch`, обёрнутый в функции с нормализацией ошибок в `ApiError` (код из тела ошибки: `bad_request`, `not_found`, `slot_conflict`). Данные — TanStack Query (инвалидация слотов после брони и создания типов). UI — shadcn/ui на Tailwind v4. Даты на wire в UTC, в UI — локальный пояс (date-fns). CORS в dev обходится Vite-proxy `/api → http://localhost:4010`.

**Tech Stack:** Vite ^8, React ^19, TypeScript, React Router ^8/^7, Tailwind CSS ^4, shadcn/ui, openapi-typescript ^7, openapi-fetch, TanStack Query ^5, react-hook-form + zod, date-fns, Vitest + Testing Library, sonner, @stoplight/prism-cli.

**Spec:** `docs/superpowers/specs/2026-08-15-frontend-design.md`

## Global Constraints

- Контракт (`main.tsp`, `tspconfig.yaml`) не изменяется.
- В API нет DELETE/PUT для типов событий и нет отмены брони — эти функции не проектируются.
- Тексты интерфейса на русском.
- Времена к API передаются в UTC (ISO 8601 с `Z`); отображение — в локальном поясе.
- Ошибки API: 400 → «Неверные данные», 404 → «Не найдено», 409 → «Слот уже занят», прочее → «Ошибка сервера».
- UI-компоненты добавляются только через `npx shadcn@latest add <name>`.

- [ ] **Step 3: Реализовать `errors.ts`**

```ts
export class ApiError extends Error {
  constructor(
    public status: number,
    public code: string | undefined,
    message?: string,
  ) {
    super(message ?? `API error ${status}`);
    this.name = "ApiError";
  }
}

const messages: Record<number, string> = {
  400: "Неверные данные",
  404: "Не найдено",
  409: "Слот уже занят",
};

export function errorToMessage(err: unknown): string {
  if (err instanceof ApiError && messages[err.status]) return messages[err.status];
  return "Ошибка сервера";
}
```

```ts
import type {
  paths,
  components,
} from "./schema";
import { api } from "./client";
import { ApiError } from "./errors";

type ErrorSchema = components["schemas"]["BadRequestError"] | components["schemas"]["NotFoundError"] | components["schemas"]["ConflictError"];

async function unwrap<T>(res: { data?: T; error?: ErrorSchema & { message: string } }): Promise<T> {
  if (!res.data) {
    throw new ApiError(
      // status недоступен в error-схеме напрямую; передаём через res.error? —
      // смотри Task 7 ниже про рефакторинг; здесь временно 500
      500,
      undefined,
      res.error?.message,
    );
  }
  return res.data;
}

export function listEventTypes() {
  return api.GET("/event-types").then((r) => unwrap(r.data));
}
// … аналогичные обёртки для остальных операций
```

> Примечание по исправлению: openapi-fetch возвращает `{ data?, error?, response }`.
> Нужен статус-код для `ApiError`, поэтому `unwrap` должен принимать `response`:
>
> ```ts
> async function unwrap<T>(res: { data?: T; error?: unknown; response: { status: number } }): Promise<T> {
>   if (!res.data) throw new ApiError(res.response.status, (res.error as { code?: string })?.code, (res.error as { message?: string })?.message);
>   return res.data;
> }
> ```
>
> Использовать этот вариант. Каждая обёртка возвращает `res.data` или бросает `ApiError`.

- [ ] **Step 7: Реализовать `dates.ts`**

```ts
import { addDays, startOfDay, format, formatInTimeZone } from "date-fns";

export function dayWindow(now = new Date(), days = 14) {
  const daysList: Date[] = [];
  for (let i = 0; i < days; i++) daysList.push(addDays(startOfDay(now), i));
  const fromISO = daysList[0].toISOString();
  const toISO = addDays(startOfDay(now), days).toISOString();
  return { days: daysList, fromISO, toISO };
}

export function formatTime(iso: string) {
  return format(new Date(iso), "HH:mm");
}

export function formatDateTime(iso: string) {
  return format(new Date(iso), "dd.MM.yyyy HH:mm");
}
```

import { listSlots } from "@/lib/api";

export function useSlots(eventTypeId: string, day: Date) {
  const dayISO = day.toISOString();
  const nextISO = new Date(day.getTime() + 24 * 3600 * 1000).toISOString();

import { useMutation, useQueryClient } from "@tanstack/react-query";
import { createBooking, type BookingCreate } from "@/lib/api";

export function useCreateBooking() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (body: BookingCreate) => createBooking(body),
    onSuccess: (_data, vars) => {
      const dayISO = new Date(vars.startAt);
      dayISO.setUTCHours(0, 0, 0, 0);
      qc.invalidateQueries({ queryKey: ["slots"] });
